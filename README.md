# Proceso de instalacion y ejecucion del proyecto

El unico prerequisito es tener python3.X instalado, las librerias necesarias vienen incluidas en las libreras preinstaladas de python.

(Estando en una terminal)


## Clonar el repositorio

```
git clone https://github.com/PySanti/ProyectoRedes
```

## Entrar al repositorio y ejecutar el proyecto

```
cd ProyectoRedes
python3 main.py
```
